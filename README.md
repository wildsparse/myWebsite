# 树洞

一方小天地。点进去先是一封信，然后是介绍，最后进树洞。
树洞里有「我们的回忆」和「留言板」，两边都能直接在网页上新增、删除。

线上地址：https://zerort.pages.dev

---

## 一、想改文字，只改一个文件

全部文案都在 `js/config.js` 里，用记事本打开就能改：

| 改动 | 位置 |
| --- | --- |
| 信的正文 | `LETTER.paras`（每个数组是一个自然段） |
| 信的开头大字 | `LETTER.heading` |
| 信的结尾、落款 | `LETTER.closing` / `LETTER.sign` |
| 音频文件名 | `AUDIO.src` |
| 介绍页那几句话 | `INTRO.lines` |
| 网站名、标签、空状态提示 | `HOLE` |

改完提交，Cloudflare 会自动重新部署，一两分钟生效。

## 二、放音频

把录音命名成 `letter.mp3`，放进仓库根目录的 `audio/` 文件夹。
建议 3MB 以内、时长 1–5 分钟。

- 没放音频时，页面不会显示播放器，信照样一个字一个字打出来。
- 文件名不叫 `letter.mp3` 的话，去 `js/config.js` 把 `AUDIO.src` 改成对应名字。

## 三、照片和留言

不用改代码。打开网站，右下角的「＋」：

- **加一段回忆**：选照片 → 自动压缩（长边 1600px，控制在 500KB 以内）→ 填标题、说明、时间 → 放进去。
- **写点什么**：选是谁 → 写内容 → 说完了。

第一次新增时要输一次「暗号」，之后这台设备会记住。
删除也是这样，鼠标移到卡片右上角会出现一个「×」。

## 四、第一次部署要做的三步

### 第 1 步：建数据库

1. 打开 <https://dash.cloudflare.com>，登录。
2. 左边菜单找 **存储和数据库 / Storage & Databases** → **D1 SQL 数据库** → **创建**。
3. 名字随便填，比如 `treehole`，创建。
4. 进去点 **控制台 / Console**，把仓库里 `schema.sql` 的全部内容粘进去，执行一次。

想一开始就有几条示例内容，再把 `seed.sql` 也执行一次（不想要就跳过）。

### 第 2 步：把数据库绑到 Pages 项目

1. 左边菜单 **Workers 和 Pages** → 点你的项目（对应 zerort.pages.dev）。
2. **设置 / Settings** → **Functions** → **D1 数据库绑定 / D1 database bindings** → **添加**。
3. 变量名必须填 `DB`，数据库选上一步建的那个。
4. 保存。**Production 和 Preview 两个环境都要加。**

### 第 3 步：设置暗号

1. 同一个项目的 **设置 / Settings** → **环境变量 / Environment variables** → **添加**。
2. 变量名填 `TREE_KEY`，值填你们之间的那个词。
3. 保存后，去 **部署 / Deployments** 页面，对最新一次部署点 **重试部署 / Retry deployment**，变量才会生效。

> 没设置 `TREE_KEY` 也能用，会退回到 `functions/_lib/auth.js` 里写的默认口令，但那个是公开在代码里的，一定要改。

### 构建配置（一般不用动）

如果 Pages 项目是新建的，填：

- 框架预设：None
- 构建命令：留空
- 构建输出目录：`/`

## 五、本地看效果

在仓库目录里执行：

```bash
python -m http.server 8899
```

浏览器打开 <http://127.0.0.1:8899>。

这时候没有后端，页面会自动切到「本地预览模式」：新增的内容只存在这台电脑的浏览器里，刷新还在，但别人看不到。想看完整效果就直接访问线上地址。

调试用的网址参数：

- `?act=intro` 直接跳到介绍页
- `?act=hole` 直接跳到树洞

## 六、文件都是干什么的

```
index.html            三幕的骨架
css/main.css          全部样式
js/config.js          所有文字内容（改这里最多）
js/letter.js          打字机、音频、节奏
js/hole.js            回忆和留言的增删、图片压缩
js/api.js             和后端说话（没后端时自动降级到本地存储）
js/app.js             把三幕串起来
functions/api/        后端的几个接口
functions/_lib/auth.js  口令校验、默认口令
schema.sql            建表
seed.sql              示例内容
_routes.json          让只有 /api/* 走函数，其余走静态文件
audio/                放录音
```

## 七、几个说明

- 照片存在 D1 里（base64），所以单张会被压到 500KB 以内。够用，但别指望存几百张高清原图；真到了那个量再换 R2。
- 口令只保护「写」和「删」，浏览是公开的。想连浏览都要口令，得再加一层，告诉我。
- 时间是按访问者本地时区显示的。
