# 请把素材放进这两个文件夹

## images/
放照片，命名 `01.jpg` `02.jpg` …… 和 index.html 顶部 `CONFIG.photos` 里的 `src` 对应。

- 格式：jpg / png / webp 都行
- 建议：长边 1200px 左右，竖图方图都行，页面会自动裁成正方形
- 数量：想放几张就放几张，改 `CONFIG.photos` 数组就行
- 图片没放对应的文件也不怕，页面会显示一个虚线占位框，不会开天窗

## audio/
放音频，默认文件名 `letter.mp3`。

- 改了文件名，就去 `CONFIG.audio.src` 改成对应名字，例如 `'audio/zero.mp3'`
- 建议：mp3，**3MB 以内**。太长对方会听不下去，太短又装不下你想说的话，60–120 秒最合适
- 音频没放也不怕，磁带机会显示一行提示，点播放按钮不会有反应

## 部署到 Cloudflare Pages
- 构建命令留空，输出目录填 `/`（仓库根目录）
- `index.html` 就是入口
