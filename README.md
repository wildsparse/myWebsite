# ZERO RT

一方小天地。点进去先是一封信，然后是介绍，最后进树洞。
树洞里三块：「我们的回忆」「留言板」「一起做清单」，都能直接在网页上增删。

线上地址：https://zerort.pages.dev

---

## 一、想改文字：全站的字都在 `js/config.js`

一个文件。信、介绍、树洞的栏目名和提示、地图底下那行、弹窗上所有按钮，
连"显示全文""先不放""放进去"这些都在里面。

（`index.html` 里那些元素现在只留一个 `data-text="memory.title"` 这样的标记，
字本身在 `config.js` 的 `COPY` 里。所以在 html 里是搜不到"加一段回忆"的，
别去那儿找。)

### 在 GitHub 上改，三步

1. 打开 <https://github.com/wildsparse/myWebsite/blob/main/js/config.js>
2. 右上角铅笔图标（Edit this file）
3. 改完滚到底，点 **Commit changes**。等一两分钟，Cloudflare 会自己重新部署。

**找不着某句话在哪一节**：在仓库页面按 <kbd>/</kbd>（或点左上角搜索框），
把那句话原样粘进去回车，直接落到那一行。

改的时候记住三件事：中文引号、括号随便用；英文单引号 `'` 是代码的边界，
正文里要用就写成 `\'`；每行末尾的英文逗号别删。

### 更新日志怎么写

树洞滚到底有一行「更新日志」，下面先露出最新的一条（最多两行，再长折起来），点开是一张纸，从新到旧记这个站改过什么。没有增删界面，内容写在 `js/config.js` 末尾的 `CHANGELOG.entries` 里。

每次改完，在**最前面**加一行就行：

```js
{ date: '2026-11-03', note: '更新日志今日上线啦！', where: '树洞' }
```

- `note` 写一句人话，别写「优化了性能」。
- `where` 可以省，写了就在下面显示成一行小字，标一下动的是哪块。
- 月份分组是按日期自动分出来的，不用管。

## 二、放音频

把录音命名成 `letter.mp3`，放进仓库根目录的 `audio/` 文件夹。

- **有声音时，文字跟着声音走**：念到哪，字出到哪；暂停，字也停住；整封念完，自动停在落款。
- 没放音频时，页面不会显示播放器，文字按打字机速度慢慢出（整封约 4 分钟），随时可以点「显示全部」。
- 文件名不叫 `letter.mp3` 的话，去 `js/config.js` 把 `AUDIO.src` 改成对应名字。
- **换了录音，要重做 `audio/timeline.json`**。文字不是按总时长平均推的，而是照着 `timeline.json`
  里量出来的真实时间点走，这样每一句都贴着嘴。重做步骤见 `scripts/README.md`。
  （不重做也能放，只是会退回平均速度，开头差一句、中间忽快忽慢。）

### 格式很要紧

扩展名必须是 `.mp3`，内容也得真的是 mp3。手机录完常常是 `.m4a`，直接改后缀名塞进来不行：
文件内容没变，服务器和浏览器会各自猜，Safari 上多半放不出声。用这句转：

```
ffmpeg -i 录音.m4a -ac 1 -ar 44100 -c:a libmp3lame -b:a 96k letter.mp3
```

语音用这个码率听不出区别，体积只有原来的三分之一，手机上不用等太久。

## 三、三块内容怎么加

不用改代码。打开网站，右下角的「＋」：

- **加一段回忆**：选照片 → 自动压缩（长边 1600px，控制在 550KB 以内）→ 填标题、说明、时间 → 放进去。
  照片、标题、说明三样里有一个就能存，只写一句话也完全可以。
- **写点什么**：选是谁 → 写内容 → 可以顺手带最多两张照片（会压到长边 1000px，点开能看大图）。
- **加一件事**：写一件想一起做的事，之后在清单里点左边圆圈就勾掉。
  勾掉的会沉到清单最下面那一行「今年一起做完了 N 件事」，点开才铺成一列——
  哪天做完的、谁做的都写着，再点一下圆圈能撤销，点「×」才是真删。

第一次新增时要输一次「暗号」，之后这台设备会记住。
删除是这样：鼠标移到卡片或条目右上角会出现一个「×」。

回忆有两种看法，右上角切换：
- **网格**：照片铺开，适合看图。
- **时间线**：按事情发生的日子排，按年份分组。

## 四、第一次部署要做的三步

### 第 1 步：建数据库

1. 打开 <https://dash.cloudflare.com>，登录。
2. 左边菜单找 **存储和数据库 / Storage & Databases** → **D1 SQL 数据库** → **创建**。
3. 名字随便填，比如 `treehole`，创建。
4. 进去点 **控制台 / Console**，把仓库里 `schema.sql` 的全部内容粘进去，执行一次。

### 第 2 步：把数据库绑到 Pages 项目

1. 左边菜单 **Workers 和 Pages** → 点你的项目（对应 zerort.pages.dev）。
2. **设置 / Settings** → **Functions** → **D1 数据库绑定 / D1 database bindings** → **添加**。
3. 变量名必须填 `DB`，数据库选上一步建的那个。
4. 保存。**Production 和 Preview 两个环境都要加。**

### 第 3 步：设置暗号

口令是一道题：「我们的小狗叫什么！（写全拼）」，答案是 `zouzou`。
题目在前端显示，答案只存在后端，比对时不分大小写。

1. 同一个项目的 **设置 / Settings** → **环境变量 / Environment variables** → **添加**。
2. 变量名填 `TREE_KEY`，值填 `zouzou`。
3. 保存后，去 **部署 / Deployments** 页面，对最新一次部署点 **重试部署 / Retry deployment**，变量才会生效。

> 不改也能用：`functions/_lib/auth.js` 里写了默认值 `zouzou`，代码是公开的，所以想换答案时记得改环境变量。
> 本地预览没有后端，用的是 `js/config.js` 里的 `HOLE.localKey`，换答案时两处一起改。

### 构建配置（一般不用动）

如果 Pages 项目是新建的，填：

- 框架预设：None
- 构建命令：留空
- 构建输出目录：`/`

## 六、本地看效果

在仓库目录里执行：

```bash
python -m http.server 8899
```

浏览器打开 <http://127.0.0.1:8899>。

这时候没有后端，页面会自动切到「本地预览模式」：新增的内容只存在这台电脑的浏览器里，刷新还在，但别人看不到。浏览器给的额度只有几 MB，存两三张照片就满了，会提示「本地存不下了」——这是正常的，上线后走数据库没这个限制。

调试用的网址参数：

- `?act=intro` 直接跳到介绍页
- `?act=hole` 直接跳到树洞

## 七、字体

正文和标题用的是**霞鹜文楷**（LXGW WenKai），SIL Open Font License，可以免费自用和分发。

字体在 `fonts/` 里，按 unicode-range 切成 97 片，由 `css/wenkai.css` 引入。浏览器只会下载当前页面实际用到的那几片，首屏通常一两百 KB，不会一次拉全量。

这样做是因为宋体、楷体这些只有电脑系统才自带，手机上一律没有，会直接退成黑体。把字体文件放在网站上，iPhone 和安卓看到的就是同一个样子。

换字体的话：`css/main.css` 顶部的 `--font-serif` 改顺序即可。
加粗只装了 Regular 一档，因为全站没有需要真正加粗的地方（伪粗体会糊）。

## 九、地图上那些亮着的地方

地图在树洞的第三个视图里。它不读回忆，单独有一张表。

地图不是一张图片，是矢量画的：全国省界是一层细线，去过的城市是另一层填色。
所以"点亮一个城市"不是在地图上点一下，而是把那个城市的行政边界画进去。

**加一个城市要两步**：

1. 打开 `scripts/make-map-vector.py`，在 `CITIES` 里加一行，格式是
   `('370200', '青岛', None)`——行政区划代码、名字、是不是现在住的地方。
   代码网上能查到，青岛是 370200，南京是 320100。
2. 跑一句 `python scripts/make-map-vector.py`，它会重新生成 `map/regions.json`。
   然后告诉我一声，我把库里那条记录也加上。

旅行不频繁，一年动一两次，这样最省事，也最不容易出错。

**加照片**：连点顶部那行日期（「2026 年 11 月 4 日 这里存着…」）五次，
会出一行提示，这时点亮着的城市块，弹出来里面就有「加一张照片」。
平时这个入口看不见。

**底图从哪来**：省级和市级的行政边界来自高德开放平台（DataV 的行政区划服务），
用等积圆锥投影铺平（标准纬线 25° 和 47°，中国地图的常规画法）。
页脚标了来源。这不是手绘的轮廓，也不是随便找的示意图——中国疆域的画法有硬性规定，
不能自己改形状，也不能把台湾、南海诸岛漏掉。右下角那个小框就是南海诸岛和九段线。

## 十、几个说明

- 照片存在 D1 里（base64）。回忆单张压到 550KB 以内，留言每张 380KB 以内、最多两张，都是为了不撞 D1 单行 1MB 的上限。够用，但别指望存几百张高清原图；真到了那个量再换 R2。
- 口令只保护「写」和「删」，浏览是公开的。想连浏览都要口令，得再加一层，告诉我。
- 时间是按访问者本地时区显示的。
- 免费额度：数据库 5GB、每天 10 万次写入，两个人用碰不到边。
