# 把录音放在这个文件夹

文件名用 `letter.mp3`，页面就会自动放出来。

- 想换名字，去 `js/config.js` 改 `AUDIO.src`
- 换了录音，记得把 `js/config.js` 里 `AUDIO.duration` 改成新录音的秒数（B 站的时长那个数），否则文字和声音会对不齐
- 没有音频也没关系，信照样一个字一个字打出来，只是不显示播放器

## 格式一定要注意

扩展名必须是 `.mp3`，内容也得真的是 mp3。

手机录完常是 `.m4a` 或 `.aac`，直接改个后缀名塞进来是不行的——文件内容没变，
浏览器和服务器会各自猜，Safari 上多半直接放不出声。要转换：

```
ffmpeg -i 录音.m4a -ac 1 -ar 44100 -c:a libmp3lame -b:a 96k letter.mp3
```

这一句会把文件压到原来的三分之一左右，语音听不出区别，手机上也不用等太久。

- 现在这一版：7 分 46 秒，96kbps 单声道，5.3MB
